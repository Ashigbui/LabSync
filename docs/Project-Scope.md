Features

Students and faculty can:
Log in (Register or sign up with school email)
View equipment by laboratory
Search for equipment
Check availability
Book equipment
Return equipment
Report damaged equipment
View safety instructions

Lab technicians/admins can:
Add, edit, and remove equipment
Approve or reject bookings
Mark equipment as available, borrowed, damaged, or under maintenance
View overdue equipment
Add maintenance notices
Generate basic equipment and booking reports

System features:
Store data in JSON or CSV files
Use a Python GUI
Fetch selected safety information from an API
Generate reports using an external library

Users
Students
Lab technicians 
Faculty and Faculty Interns
